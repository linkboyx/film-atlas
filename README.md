# 银幕年鉴 · 1988—2026

本地电影资料库，覆盖1988–2026共39个年份。已取消原版每年20–30部的数量上限，收录标准和数据完整度在网页“收录与数据说明”“逐年收录情况”中展示。

## 使用

双击 `打开电影资料库.cmd`，或直接用浏览器打开 `dist/index.html`。影片资料和已下载海报均在本地，断网仍可搜索、筛选和浏览；网络字体加载失败时使用系统字体。也可以在本目录运行 `node server.mjs`，访问 `http://localhost:4173/`。

支持片名、导演、演员搜索；年份、类型、国家/地区、入选理由、IMDb/豆瓣最低评分、全球票房门槛组合筛选；排序、卡片/表格视图、浏览器本地片单、筛选结果CSV导出。筛选条件记录在网址查询参数中。

## 数据

- `dist/catalog.json` 为完整可编辑数据；`dist/data.js` 为页面使用的同一数据快照。
- 新门槛取并集：年度全球票房前100；或IMDb≥7.0且评价≥5000；或豆瓣≥7.5且评价≥5000；或重要电影奖项获奖。原精选保留，不限制每年数量。
- IMDb：官方 title.ratings.tsv.gz，按影片 tt ID 匹配，保留评价人数。
- 影片类型、首映年份与身份：IMDb官方title.basics；中文名和别名：官方title.akas，优先中国大陆译名，保留港台别名。
- 新增导演、演员及地区：按IMDb ID匹配Cinemeta公开元资料，保留每片链接；未取得的字段明确待补核，不编造。可以筛选“仅显示人物、地区资料完整”。
- 豆瓣：Top250、公开类型榜单、站内搜索结果，保留每片来源。未核实评分为空。
- 票房：Box Office Mojo、The Numbers、影片资料页。来源、美元金额、范围、说明分别保存。`boxOffice.comparable` 表示来源全球统计口径可用于页面全球票房筛选；false 仍可展示资料页金额，但不参与全球门槛和排名。早期电影的Worldwide记录也可能缺少历史地区数据；不视为完整最终收入。
- 奖项：已核实的重要奖项摘记，非完整获奖提名清单。空白不代表未获奖。
- “奖项汇总”单独展示Cinemeta的获奖/提名数量原文，不冒充逐项核实的具体荣誉，不参与获奖筛选。
- 封面：`dist/posters/` 保存真实图片；`posterLocal`标记本地图片，`posterSource`保留来源。优先使用已核对的Wikipedia海报，新增影片使用按IMDb ID提供的Cinemeta/Metahub封面。
- 年份按首次公开首映或发行归档，包含电影节首映。合拍影片可含多个国家/地区。
- 访问日期2026-11-01；非实时数据。2026仅年内快照，无法提前覆盖尚未发生的年终结果。

研究缓存位于同级目录 `../research/`。运行 `node build-expanded-catalog.mjs` 合并原片库、扩容资料、官方中文名和本地封面，再运行 `node verify-catalog.mjs`、`node verify-posters.mjs` 检查数据及图片。旧版 `build-catalog.mjs` 仅保留作历史参考，不能用于更新扩展版。

## 本地保存

当前修改保存于本地 `dist`，无需在线部署、服务器运行时或密钥。备份网页时请一起保存整个 `dist`，包括`posters`子目录。实际收录数和封面覆盖率见`coverage.json`及网页说明。

## GitHub Pages 与定时更新

已准备 `.github/workflows/pages.yml`，支持推送发布、手动发布和每天更新已有影片的 IMDb 评分后发布；上传授权与 Pages 设置仍需完成。详细步骤见 [GITHUB-PAGES.md](GITHUB-PAGES.md)。无需保存 GitHub 密码；目标仓库信息可填写在 `deployment.local.json`（参考 `deployment.example.json`）。豆瓣、票房、奖项和新增影片尚未接入自动更新。
